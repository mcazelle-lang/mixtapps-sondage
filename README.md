# 📊 Sondage express

Pose une question, ajoute jusqu’à 6 réponses et partage le lien : le sondage tient tout entier dans l’URL. Résultats en barres colorées, sans inscription.

- **Remixer** : sur Mixtapps, « ⚡ Remixer le code » lance l’app dans ton navigateur et un agent IA modifie
  son code ; ton remix est publié sur une branche GitHub à ton nom.

## Lancer en local

Une app statique (HTML, CSS, JavaScript, sans dépendance) : ouvre `index.html`, ou avec Node :

```bash
npm install
npm run dev
```
